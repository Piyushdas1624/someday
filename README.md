## ⚡ Overview

**Someday** is a satirical productivity application built for the **DEV.to April Fools Challenge**. It explores procrastination UX through humorously evasive interactions, micro-animations, and client-side web technology.

---

## ✨ Key Highlights

- ⏱️ **Evasive Interaction Design:** Dynamic task deferral mechanics reflecting real-world procrastination.
- 💾 **Client-Side Persistence:** Local browser state saving without external servers.
- ⚡ **Zero-Dependency Web Stack:** Native HTML5, CSS3, and JavaScript implementation.
